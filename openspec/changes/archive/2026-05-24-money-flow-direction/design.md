# Money Flow Direction - Design

## 1. Concept & Vision

资金流向Sankey图帮助投资者直观理解过去5个交易日资金在不同行业板块间的流转趋势。通过垂直布局展示每日Top 8板块，按净流入金额排序，以U型折线连接相邻日期的同一板块，形成清晰的资金流动路径。视觉风格延续项目的复古黄铜主题。

## 2. Design Language

### Aesthetic Direction
复古黄铜/羊皮纸风格，与整体网站主题一致。使用暖色调金属色系。

### Color Palette

**板块颜色（基于名称哈希）**:
```typescript

  "#d4a84b", // gold

  "#8b5a3c", // brown
  "#b88a2c", // bronze

```

**流出颜色**: `#5a4a3a` (muted brown)

### Typography
- Georgia serif字体
- 日期标签: 13px/11px, 600 weight
- 板块名称: 12px, 600 weight
- 金额标签: 11px, regular

### Layout
- 垂直布局：最新日期在上，最老日期在下
- 每个日期截面：日期标签 + 板块条形图
- 右侧区域：U型折线连接相邻日期的同一板块
- 每条折线分配独立的水平通道，避免竖线重叠

### Motion Philosophy
- 交互反馈即时（无延迟动画）
- 高亮/弱化状态使用透明度变化

## 4. Features & Interactions

### 核心功能

1. **数据加载**
   - 组件挂载时自动加载5天Top 8数据
   - 显示加载状态："加载中…"
   - 错误时显示："数据加载失败: {error}"
   - 空数据时显示："暂无数据"

2. **板块条形图**
   - 每行显示一个板块，宽度对应净流入金额
   - 正值（流入）使用板块专属颜色
   - 负值（流出）使用muted brown颜色
   - 金额标签：流入显示"+{x}亿"，流出显示"{x}亿"

3. **U型折线连接**
   - 相邻日期的同一板块用折线连接
   - 每条折线分配独立水平通道（竖线部分不重叠）
   - 折线颜色与板块颜色一致
   - 透明度：高亮板块折线0.95，普通0.55，弱化0.1

4. **点击高亮**
   - 点击折线或图例按钮：高亮对应板块，弱化其他
   - 再次点击：恢复正常显示
   - 点击空白区域：清除高亮状态
   - Tab栏右侧显示当前选中的日期

5. **底部图例**
   - 显示跨5天出现的板块（至少2天出现才有连接线）
   - 按5日累计净流入排序（降序）
   - 显示板块颜色块 + 名称 + 累计金额
   - 点击图例项可切换高亮状态
   - 累计金额正数绿色，负数红色

### 边界情况
- 某天板块数不足8个：显示实际数量
- 某板块在某天缺席：连接线在该日期处断开（折线只连接连续出现的日期）

## 5. Component Inventory

### SectorMoneyFlowSankey
- **Default**: 显示5天Top 8板块条形和U型折线
- **Loading**: 显示"加载中…"占位符
- **Error**: 显示错误信息
- **Empty**: 显示"暂无数据"
- **Highlighted**: 一个板块高亮，其他弱化

### Tab栏
- 左侧：两个Tab按钮（资金流向、机构龙虎榜）
- 右侧：当前选中子模块的日期（仅当有数据时显示）

## 6. Technical Approach

### 后端
- `GET /api/stock/sector-money-flow?days=5&top_n=8`
- 调用Tushare `moneyflow_ind_dc` 接口
- 过滤 `content_type == "行业"` 的数据
- 罗马数字后缀去重合并
- 5分钟缓存

### 前端
- 自定义Canvas渲染（非ECharts）
- ResizeObserver响应容器宽度
- 哈希函数为板块名称分配颜色
- 点到线段距离算法实现点击检测
- 状态：`data`, `containerWidth`, `isMobile`, `highlightedSector`
