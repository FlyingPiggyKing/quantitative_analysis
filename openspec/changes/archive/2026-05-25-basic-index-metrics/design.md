## Context

当前"投资分析"模块只有"资金流向"和"机构龙虎榜"两个子 tab，需要新增"A股指数指标"功能，展示主要指数的 PE-TTM 估值情况。

**现有技术栈：**
- 前端：Next.js + React + TypeScript，使用 Tailwind CSS
- 后端：Python FastAPI，通过 API 路由调用 Tushare 获取数据
- 缓存：暂无统一的指数数据缓存机制

## Goals / Non-Goals

**Goals:**
- 在"投资分析"模块下新增"指数指标"子 tab
- 展示 6 个主要 A 股指数的 PE-TTM 数据
- 支持 5 年/10 年时间范围选择
- 单指数独立刷新，避免全量请求
- 每日缓存过期策略

**Non-Goals:**
- 不实现实时推送（使用每日缓存即可）
- 不支持港股/美股指数
- 不实现复杂的 PE 趋势图（仅展示当前值和分位）

## Decisions

### 1. 指数列表及排序

**Decision:** 按"科创板 > 创业板 > 主板"顺序排列

**Rationale:** 科创板和创业板是当前市场热点和重点，放在最上面符合用户关注度。

| 指数 | ts_code | 备注 |
|------|---------|------|
| 科创50 | 000688.SH | 科创板 |
| 创业板指 | 399006.SZ | 创业板 |
| 上证指数 | 000001.SH | 主板 |
| 深证成指 | 399001.SZ | 主板 |
| 沪深300 | 000300.SH | 主板 |
| 中证500 | 000905.SH | 主板 |

### 2. 指标计算逻辑

**Decision:** 使用 30/70 百分位作为机会值/危险值

**Rationale:**
- 这是市场上主流平台（乌龟量化、理杏仁等）的通用做法
- 30% 以下为低估机会区，70% 以上为高估危险区
- 计算公式：`opportunity = np.percentile(sorted_pe, 30)`

### 3. 缓存策略

**Decision:** 每个指数独立缓存，次日零点过期

**Rationale:**
- 不同指数数据独立性高，无需全局锁
- 每日过期符合日线数据更新频率
- 实现简单，使用 `datetime.now().date()` 作为缓存 key 一部分

### 4. 组件结构

**Decision:** 新增 `IndexMetricsPanel.tsx` 组件，复用现有子 tab 机制

**Rationale:**
- 遵循现有 `SubModuleTabs` 架构
- 每个指数卡片独立管理刷新状态
- 时间范围选择器放在卡片内部

### 5. 后端 API

**Decision:** 复用 `index_dailybasic` 接口，通过 `start_date`/`end_date` 获取历史数据

**Rationale:**
- 无需新增后端 API
- 直接使用 Tushare 现有数据源
- 在后端做百分位计算，减少前端计算压力

## Risks / Trade-offs

| Risk | Mitigation |
|------|------------|
| Tushare API 调用次数限制 | 每个指数独立请求，单次最大 3000 条（约 8 年数据） |
| 历史数据缺失 | 科创板 2019 年成立，5 年数据范围可覆盖 |
| 缓存击穿 | 每日过期不会重复计算 |

## Open Questions

- 是否需要展示 PE 历史走势图？（当前仅展示当前值和分位）
- 中证500 数据可靠性是否足够？

## 新增：行业指数 PE 估值功能

### Context

在指数估值基础上，新增行业指数 PE 估值功能，允许用户选择申万一级行业，查看该行业的 PE 走势曲线及估值指标。

### Goals

- 在指数估值下方新增"行业估值"区块
- 提供申万一级行业下拉选择器（28个行业）
- 展示行业 PE 历史曲线
- 展示行业当前 PE、百分位、机会值、危险值等指标
- 支持 5 年/10 年时间范围切换

### Decisions

#### 1. 行业数据来源

**Decision:** 使用 `sw_daily` 接口获取申万行业 PE 数据

**Rationale:**
- 申万行业指数使用 `sw_daily` 接口，与宽基指数使用的 `index_dailybasic` 不同
- `sw_daily` 接口直接返回行业 PE 值

#### 2. 行业列表

**Decision:** 预设申万一级行业列表（28个），不动态获取

**Rationale:**
- 申万一级行业分类相对稳定，28个行业长期不变
- 避免每次加载时额外 API 调用
- 可后续扩展为从 Tushare `index_classify` 动态获取

#### 3. 指标计算

**Decision:** 与指数估值逻辑一致，使用 30/70 百分位

**Rationale:**
- 保持与指数估值 UI 风格一致
- 复用 `calculate_pe_percentile` 函数

#### 4. 图表展示

**Decision:** 行业估值图表风格与指数估值完全一致

**Rationale:**
- 包括机会值/危险值虚线
- 指标网格布局一致
- 用户体验统一
