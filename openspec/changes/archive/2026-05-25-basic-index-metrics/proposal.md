## Why

当前投资分析模块缺少对 A 股主要指数（如上证、深证、创业板、科创板等）估值指标的展示功能。投资者无法直观看到各指数的 PE-TTM 历史分位、机会值、危险值等关键估值数据，难以判断当前市场整体估值水平。

## What Changes

1. 在"投资分析"模块下新增"A股指数指标"子模块 tab
2. 展示 6 个主要 A 股指数：科创50、创业板指、上证指数、深证成指、沪深300、中证500
3. 每个指数显示：当前 PE-TTM、机会值（30百分位）、危险值（70百分位）、当前百分位
4. 支持 5 年/10 年时间范围切换（独立刷新）
5. 每日缓存，过期后重新计算

## Capabilities

### New Capabilities

- `index-pe-ttm-metrics`: A 股指数估值指标展示
  - 指数列表展示（科创50、创业板指、上证指数、深证成指、沪深300、中证500）
  - PE-TTM 滚动市盈率数据获取
  - 机会值/危险值百分位计算（5年/10年可选）
  - 单指数独立刷新机制
  - 每日缓存策略

### Modified Capabilities

- `module-layout-tabs`: 投资分析模块新增子 tab

## Impact

- 前端：新增"指数指标"子 tab 及相关组件
- 后端：新增指数 PE 数据 API 接口或数据处理逻辑
- 缓存：每日过期缓存策略
